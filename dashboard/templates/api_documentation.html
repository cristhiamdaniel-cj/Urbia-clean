UrbIA IoT - Smart City Manizales REST API

Base URL: http://localhost:5001/api\\

Sensores
GET /api/sensors
Obtiene la lista completa de sensores IoT con su información de ubicación, tipo, prioridad y última telemetría.

Métricas del Sistema
GET /api/metrics
Obtiene métricas agregadas del sistema: total de sensores, sensores activos y alertas críticas.
Respuesta (200 OK):
{ "total_sensors": 15, "active_sensors": 15, "critical_alerts": 0 }
Eventos SDN
GET /api/events
Obtiene el historial de decisiones de enrutamiento del controlador SDN.
Parámetros opcionales:
Parámetro Tipo Descripción Por defecto
limit integer Número de eventos a retornar 50
Respuesta (200 OK):

50 eventos recientes
Análisis Matemático SDN
GET /api/sdn-analysis
Obtiene análisis matemático en tiempo real del controlador SDN: latencia, throughput, congestión, estrategias y estadísticas.

Códigos de Respuesta
Códigos HTTP:
  • 200 OK - Solicitud exitosa
  • 400 Bad Request - Parámetros inválidos
  • 404 Not Found - Recurso no encontrado
  • 500 Internal Server Error - Error del servidor
  • 503 Service Unavailable - Servicio no disponible temporalmente
Ejemplos de Uso
cURL:
# Obtener todos los sensores curl http://localhost:5001/api/sensors # Obtener análisis SDN curl http://localhost:5001/api/sdn-analysis # Obtener eventos recientes curl http://localhost:5001/api/events
Python:
import requests # Obtener sensores response = requests.get('http://localhost:5001/api/sensors') sensors = response.json() # Obtener análisis SDN response = requests.get('http://localhost:5001/api/sdn-analysis') analysis = response.json() print(f"Latencia: {analysis['avg_latency']}ms") print(f"Throughput: {analysis['total_throughput']} pkt/s")
JavaScript (Fetch):
// Obtener telemetría fetch('http://localhost:5001/api/telemetry/current') .then(response => response.json()) .then(data => { console.log('Telemetría:', data); });
